# Taddy API Skills, MCP Server, and Docs

## Overview

We offer a couple ways to use our API with AI tools:

1. **Taddy API Skill** - If you want to build Taddy Podcast API into your app, our [open-source skill](https://github.com/taddyorg/taddy-api-skills)  gives your AI coding tool (Claude Code, Codex, Cursor etc.) useful context like our API docs, GraphQL schema, and best practices to follow.
2. **MCP Server for Taddy API** – Use Taddy API’s MCP server if you want to get podcast data (including transcripts) inside ChatGPT, Claude, or any MCP-compatible app. ex) You can ask to "Find recent episodes that mention [my company] and summarize both the positive and negative feedback"*.* 
3. **Taddy API Docs** - If you want to provide to your AI coding tool our docs & GraphQL schema. It's the building blocks we used to make the Taddy API Skill.

## Taddy API Docs

Here are two resources that you can provide your AI coding tool to give it useful context about our API, we used this as input for the [Taddy API Skill](./ai-tools-mcp-server.md):

2. [**Taddy API Documentation**](https://ax0.taddy.org/docs/taddy-api-docs.md) - The full documentation for Taddy Podcast API in one big markdown file.
